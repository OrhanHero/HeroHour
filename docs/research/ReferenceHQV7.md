# Reference HQ V7 — faceted Aegis command tower

Original mesh authored from the supplied white/blue base reference (`Codex-Bild 1. Sept. 2026, 01_22_20.png`, right-hand HQ) and battle composition (`01_22_00.png`). Both supplied images and the actual V6 Aegis screenshot were inspected before modelling.

The final revision replaces both the earlier fortress and the rejected flat warehouse/large-garage interpretation with a faceted command tower. It has a stepped octagonal dish roof, blue command windows around the upper floor, broad diagonal cheek armor, a small personnel entrance, fitted wall panels and an asymmetric low service wing with pipes and roof rails. The entrance is not a vehicle garage. A shallow concave parabolic satellite dish sits on the roof; this is an original approximation of the reference rather than an exact reconstruction.

## Reproduce and integrate

The dependency order is **source → bake → mesh import → surface import → portrait render/import**. Rebuilding geometry after baking invalidates its atlas; rerunning a mesh importer after the surface importer restores intermediate materials and therefore requires the surface import again.

1. **Source:** run Blender 5.2 background with `Scripts/art/build_reference_hq_v7.py`. Inspect `Art/Models/ReferenceHQV7/SM_RV7_AegisHQ.png` and the adjacent JSON manifest. This generates the final `.blend` and `.fbx`, including UV0 and the small entrance. Build the other three reference sources before a full four-model refresh.
2. **Bake:** run Blender with `Scripts/art/bake_reference_surfaces_v7.py -- --only Aegis_HQ` for the changed HQ, or explicitly request all four keys `Aegis_HQ Ember_HQ Aegis_APC8 Ember_APC8`. The default selection is APCs only, so it does not refresh this HQ automatically. HQ atlases use 2048², APC atlases 1024². The baker writes original Albedo, ORM and EmissionMask images plus hashes to `Art/Textures/ReferenceV7/metadata.json`; it checks that source blend and FBX bytes remain unchanged.
3. **Mesh import:** execute `Scripts/art/import_reference_hq_v7.py` through Unreal Python. It imports `/Game/HERO/ReferenceV7/Meshes/SM_RV7_AegisHQ` and changes only `/Game/HERO/DataV4/D_Aegis_HQ.static_mesh` among gameplay definitions. Its definition stats/icon preservation is asserted. The other models have their separate importers. No map or gameplay values are edited by this HQ importer. Its semantic material assignments are intermediate, not the final baked appearance.
4. **Surface import:** after all matching mesh imports, execute `Scripts/art/import_reference_surfaces_v7.py`. It validates source/FBX/texture hashes and binds `/Game/HERO/ReferenceV7/Materials/M_RV7_Baked_Aegis_HQ` to every HQ slot. Texture parameters `Albedo`, `ORM`, `EmissionMask` refer to the matching `T_RV7_Aegis_HQ_*` assets. Albedo is sRGB/TC_Default; the masks are linear/TC_Masks. Runtime must preserve the material's neutral white Tint, including after a damage flash.
5. **Portrait render/import:** execute `Scripts/art/render_reference_portraits_v7.py` only after the final source and atlases exist. It reads those same baked surfaces for all four reference models and also renders the nine other Ember roles with green faction markings. Then execute `Scripts/art/import_reference_portraits_v7.py` through Unreal Python to reimport exactly those thirteen existing portrait textures. The remaining nine Aegis PNGs and metadata records are preserved unchanged.
6. Build/package, run the actual Presentation/UI checks and inspect a current Unreal front/side capture. Studio renders do not establish package or lighting acceptance. Rerunning the generic DataV4 creator can restore old role meshes; reapply the mesh and surface stages afterwards.

## Geometry validation

35,568 triangles; 7.10 × 6.80 × 5.594973m source bounds (approximately 5.595m tall). Runtime HQ scale1.5 gives a 10.65 × 10.20m footprint inside the existing12 ×12m HQ blocker. HQ actors spawn atZ110cm; runtime mesh compensation adds55cm. Source minimumZ−110cm therefore produces world groundZ0 after scaling. Source maximumZ is449.497cm. Exact bounds and FBX SHA-256 are in the adjacent JSON manifest.

The Blender export is imported back and actual world bounds are compared against the source. The Unreal mesh importer independently validates bounds, including FBX Y mirroring. The final source records front normal+Y in Blender and−Y in Unreal after reflection; it does not rely on the earlier exploratory orientation. Semantic slot names are retained, while the final surface stage assigns the model-local baked material to all slots. Albedo contains the white/blue design and baked variation; ORM stores AO/roughness/metallic, with a separate emission mask. No generated collision is added; gameplay continues to use the existing HQ footprint.

## Limits

This is a new silhouette, architectural layout and original UV-baked surface pass, not finished production art. Surface atlases add geometry-derived and procedural variation; they do not provide a new normal-map detail pass or guarantee a convincing worn finish at RTS distance. Dish and other parts are static joined geometry; rotation needs separate components. No destruction stages, moving doors, traversable interior or hand-authored LOD chain. Panel and pipe placement remains an original simplification of the concept. The source preview is studio-lit and does not prove the final atlas appearance, runtime lighting or concept fidelity. A current package screenshot remains mandatory.

## Matching portraits

`Scripts/art/render_reference_portraits_v7.py` refreshes exactly thirteen existing 512×512 RGBA portraits: four atlas portraits (Aegis HQ/Combat and Ember HQ/Combat) plus the nine remaining Ember roles. The four reference portraits use the same final Albedo/ORM/EmissionMask atlas files as the runtime models; the script validates their hashes and confirms that each atlas matches its source blend. The nine legacy Ember portraits use the existing geometry with the green faction PBR palette. Runtime Team/Neon markings for those legacy roles are also green, while enemy health bars and selection indicators keep their gameplay colors.

The script checks nonempty alpha bounds with >8px margin, unchanged source blend SHA-256 and unchanged PNG hashes and metadata records for the remaining nine Aegis portraits. `Scripts/art/import_reference_portraits_v7.py` reimports only the thirteen matching texture assets and verifies the rendered PNG hashes; it does not modify gameplay definitions. Completion markers: `REFERENCE_PORTRAITS_V7_COMPLETE 13; remaining 9 Aegis images and records unchanged` and `REFERENCE_PORTRAITS_V7_IMPORT_PASS 13`. These markers are reproduction criteria; current package results are recorded by Root separately.
